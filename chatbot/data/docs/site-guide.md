# Using the Site

This portfolio is built as a fully interactive Windows XP desktop. Here's how to
get around.

## Getting started

When the site loads you see an XP-style login screen. Click Michael's user name
("Michael Troy Swayney") to log in and reach the desktop.

## General navigation

- **Open something:** double-click any desktop icon to open its window. (On
  touch devices, tap to open.)
- **Move a window:** click and drag its blue title bar.
- **Close a window:** click the red **×** in the top-right corner of the window.
- **Taskbar:** open windows appear in the taskbar at the bottom; a live clock
  sits in the system tray on the right.
- **Start menu:** click the **start** button (bottom-left) for quick links to My
  Computer, Music, Internet, and the Recycle Bin.

## Desktop icons

- **My Computer** — opens Local Disk (C:), which contains three folders: **About
  Me**, **Projects**, and **Contact Me**. These hold Michael's bio, his project
  write-ups, and his contact details.
- **about me.txt** — a Notepad window with Michael's bio.
- **Internet Explorer** — opens Michael's résumé (a PDF) in an IE-styled browser
  window.
- **SkiFree** — the classic skiing game (see Games below).
- **Minesweeper** — a playable version of the classic puzzle game.
- **Music** — opens a Music folder; see Music below.
- **My Pictures** — a photo folder; see Pictures below.
- **Recycle Bin** — empty (nostalgic decoration).
- **Totse.com** — a retro-themed link / easter egg.

## Games

**SkiFree** — Ski downhill and avoid the obstacles. Use the **arrow keys**, or on
a touch screen **tap the left/right side** of the game canvas to steer. Your
Distance (in meters) and Speed are shown as you go; if you crash, a Game Over
screen lets you Play Again.

**Minesweeper** — The classic puzzle. There are **10 mines**. **Click** a tile to
reveal it and **right-click** to flag a suspected mine. Use the **New Game**
button to start over.

## Music

Open the **Music** icon to find the track **"White Iverson"**. Double-click it to
launch a Windows Media Player–style window that plays **Post Malone — White
Iverson**, complete with play/pause, a seekable progress bar, and an animated
visualizer.

## Pictures

Open **My Pictures** to find a photo titled **"Rhiannon's house 2004."** Open it
to view the picture, then click the photo to see it full-size in a Windows
Picture and Fax Viewer window.

## Résumé

Michael's résumé is available on the site — open the **Internet Explorer** icon to
read it in the browser window.
